# Game Agent · 메뉴 게임 기록 및 더미 검증

Python 3.10 이상을 사용합니다. 기존 Windows 기록기는 기본 포함된 Tkinter만 필요합니다. 화면 기반 워크플로우 코어에는 Pillow가 추가로 필요합니다. 녹화→그래프 변환, 화면 판단, 실행 상태·기록, 후보 관리와 평가 코드를 구현했으며, 실제 자동 조작과 외부 VLM 연결은 아직 별도 연결이 필요합니다.

## 화면 기반 워크플로우 코어

설치, 그래프 생성, 코드 읽는 순서, 실행 함수 연결과 평가 예제는 [WORKFLOW.md](WORKFLOW.md)를 참고하세요. 기존 `scenario.json`과 새 `graph.json`은 목적과 형식이 다릅니다. 기존 기록·예제는 그대로 사용할 수 있습니다.

## 시작

프로젝트 폴더에서 실행합니다.

```powershell
python -m game_agent gui
```

1. 게임을 창 모드로 열고 창 목록을 새로고침합니다.
2. 대상 창, 작업 목표, 완료 판정 기준을 입력합니다.
3. 기록 시작을 누르고 대상 게임 창으로 전환합니다.
4. 작업을 직접 수행합니다. F9는 주요 단계 표시, F8은 중단입니다. 이 키는 게임에도 전달되므로 게임 단축키와 충돌하면 GUI의 중단 버튼을 사용하세요.
5. 결과는 현재 폴더의 `recordings/<시각>/`에 저장됩니다. 기존 폴더는 덮어쓰지 않습니다.

명령줄로도 실행할 수 있습니다.

```powershell
python -m game_agent windows
python -m game_agent record --hwnd 123456 --output recordings/my-session --goal "보상 1회 수령" --completion "보상 수령 완료 표시와 잔액 증가" --fps 2 --duration 300
```

`123456`은 실제 창 목록의 핸들로 바꿉니다. F8로 종료합니다. 기본 최대 시간은 5분입니다. 화면·입력 수집은 지정 창이 활성화된 동안 수행되며, 포커스 이탈 시 대기합니다. 다른 창으로 이동하면서 놓은 키/버튼의 해제 이벤트는 이전 입력을 닫기 위해 기록할 수 있습니다.

## 기록 형식과 한계

- `session.json`: 목표, 완료 기준, 시작 UTC, 설정, 완료/실패 상태, 화면·이벤트 수.
- `events.jsonl`: 이벤트 ID와 세션 시작 기준 `t_ns`, 프레임, 클릭·이동·휠·키 입력, 포커스 변화, F9 표시, 오류.
- `frames/*.png`: 게임 창의 보이는 클라이언트 영역을 연속 캡처한 무손실 압축 이미지. 프레임 이벤트에는 캡처 시작/종료 시각과 해당 창 좌표가 있습니다.

입력 이벤트 훅과 화면 캡처는 같은 단조 시계를 사용합니다. 로그 쓰기 순서가 미세하게 다를 수 있으므로 분석 시 `t_ns`, 이벤트 ID 순으로 정렬합니다. 키 입력은 문자열이 아닌 가상 키 코드와 스캔 코드로 저장됩니다. 텍스트 입력, IME 결과, 게임패드, 추가 마우스 버튼은 이 버전의 재현 대상이 아닙니다.

PNG 용량은 화면 복잡도에 따라 달라집니다. 처음에는 짧은 기록으로 용량과 화면을 확인하세요. 캡처·압축 처리 시간 때문에 실제 빈도는 설정 FPS보다 낮을 수 있습니다. MP4 영상은 만들지 않으며 빠른 일시적 화면은 누락될 수 있습니다.

보이는 화면을 캡처하므로 창을 가리거나 화면 밖으로 이동하지 마세요. 최소화·비활성화 시 대기하며 종료된 창은 실패로 기록합니다. 독점 전체화면, 보호된 화면, 권한이 다른 게임의 입력은 별도 실게임 검증이 필요합니다. Windows가 수집한 입력은 게임의 실제 수신·처리를 보장하지 않습니다. 강제 종료·전원 차단 시 `status=recording`이 남은 세션은 불완전한 기록입니다.

## 더미 게임

```powershell
python -m game_agent demo
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. `Open missions → Complete mission → Claim reward` 버튼을 누르면 완료됩니다. 잘못된 위치를 클릭하면 화면이 유지됩니다. 처음부터 재시작하거나 실행 결과를 JSON으로 저장할 수 있습니다. 서버는 localhost에서만 열립니다. 종료는 Ctrl+C입니다.

`검사용 그래프 열기`는 상태 경로와 실행 이력을 표시하는 읽기 전용 검사 화면입니다. 범용 그래프 편집기는 아닙니다. 자동화 평가 시 에이전트에게 내부 노드나 정답 JSON을 제공하지 않고 화면·입력 인터페이스만 제공해야 합니다.

`examples/menu_demo/`에는 합성 화면, 입력 기록, 세션 메타데이터, 기대 워크플로가 있습니다. 실제 사용자의 기록을 분석한 결과가 아닙니다. 아래 명령으로 예제를 재생성하고 검증합니다.

```powershell
python scripts/build_fixture.py
python -m game_agent validate examples/menu_demo/scenario.json
python -m unittest discover -s tests -v
```

## 기록 분석 스킬 초안

프로젝트 스킬은 `.agents/skills/recording-to-workflow/SKILL.md`에 있습니다. 에이전트에게 해당 파일과 기록 묶음을 제공하면 이전 대화 없이 분석 절차와 출력 계약을 확인할 수 있습니다. 프로젝트 스킬 탐색이 지원되지 않는 환경에서는 파일 경로로 직접 읽도록 요청하세요.

스킬은 근거 연결, 안정적인 ID, 관찰/추정 구분, 성공 근거, 불확실성, 재현성 비교 기준을 정의합니다. 분석 실행기는 아직 없으며 실제 기록 확보 후 이 프로토콜을 검증·수정해야 합니다. 현재 재생 형식은 고정 화면 크기와 왼쪽 클릭 전환만 지원합니다. 기록기는 더 많은 입력을 수집하더라도 분석 스킬이 지원하지 않는 전환을 임의 변환하지 않도록 명시했습니다.

다른 사용자에게 전달할 때는 이 저장소의 코드·스킬·예제를 함께 전달하고, 개인 기록은 별도로 필요한 범위만 전달합니다. 전역 스킬 설치나 플러그인 배포는 수행하지 않습니다.
